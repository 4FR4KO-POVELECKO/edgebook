# Edgebook

Дневник трейдера: найди своё преимущество (edge) в собственных сделках.

Локальное веб-приложение для ведения торгового журнала. React + TypeScript + Vite, данные хранятся в IndexedDB браузера (без сервера).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/
```

## Возможности

- **Сделки** — long/short, вход/выход, объём, комиссия, стоп/тейк, множитель контракта, открытые позиции. Авторасчёт P&L, R-multiple, план R:R, доходности. Калькулятор объёма по риску % от баланса. Теги, ошибки, эмоция, оценка исполнения, заметки, скриншоты (в т.ч. вставка из буфера). Фильтры, сортировка, импорт/экспорт CSV. Клавиша `N` — новая сделка.
- **Календарь** — месяц с P&L по дням (цвет по величине), итоги недель, лучший/худший день, обзор года по месяцам. У каждого дня — план, итоги и настроение.
- **Стратегии** — описание, рынок, таймфрейм, правила. Правила становятся чек-листом в сделке; для каждой стратегии — статистика, кривая баланса и процент соблюдения правил.
- **Аналитика** — win rate, profit factor, матожидание, payoff, средний R, просадка, серии; кривая баланса и просадки; P&L по дням, дням недели, часам; распределение R; long vs short; время удержания; разбивки по стратегиям, тикерам, тегам, эмоциям, оценкам; «цена ошибок» и сравнение сделок с соблюдённым и нарушенным чек-листом.
- **Настройки** — стартовый баланс, валюта, риск на сделку, JSON-бэкап/восстановление, демо-данные.

P&L сделки относится к дню выхода.
